# Security policy

## Reporting a vulnerability

Please use GitHub's **Report a vulnerability** / private security advisory flow for this repository when possible. Do not publish exploit details in a public issue before a fix is available.

A useful report includes:

- ReForge version or commit
- Operating system and Python version
- A minimal reproduction
- Impact and affected component
- Any logs with secrets, tokens, personal paths, or device identifiers removed

## Scope

Security reports about ReForge itself are welcome, including command injection, unsafe archive handling, plugin-loading flaws, credential exposure, and dependency issues.

ReForge is intended for software, devices, and environments you own or are explicitly authorized to test.
